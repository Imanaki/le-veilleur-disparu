LE VEILLEUR DISPARU — V4.2

Accès : 1 EVEIL, 2 VEILLE, 3 ECHO, 4 LIEN, 5 ABSENCE.
Réponses : 5, 1, 1, 0. Ordre final : 05/11. Code final : 0511. Récompense : casier identifié dans les messages cachés. Anniversaire : Siran.

Fil narratif : anomalie caméra > porte de l’œil > transmission radio > porte du sablier > passage de service > confirmation que le Veilleur est sorti sain et sauf.

Leaderboard : 100 % statique via localStorage. Il mesure le temps depuis la première ouverture du site, compte chaque indice distinct ouvert et stocke les pseudos sur le navigateur courant uniquement. Pour un classement partagé entre appareils, un backend serait nécessaire.

Puzzles : aucune numérotation sur les pièces. Les symétries sont prises en compte via data-sym (45, 90, 180 ou 360 degrés selon la forme).

V4.1 : niveau d’aide réduit sur toutes les pages. Les textes signalent une anomalie sans nommer la mécanique. L’énigme audio ne mentionne plus les durées, les sons courts/longs ni le Morse. Le journal de l’énigme 1 n’indique plus explicitement quelle ligne est humaine. Correction du demi-cercle de l’œil : un demi-cercle n’est plus traité comme symétrique à 180°, et toute pièce acceptée est redessinée dans l’orientation canonique du patron pour éviter un verrouillage visuel inversé.

V4.2 : suppression de la note sur le mur dans l’énigme 1; retrait des annonces vers les énigmes suivantes; énigme 5 reformulée sans mention explicite des mails; rapport final sans nom du propriétaire du casier; nouvel indice anniversaire : volley + amie d’un Ange.
